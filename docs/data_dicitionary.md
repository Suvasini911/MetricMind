# MetricMind Data Dictionary

## Corporate Sales Dataset

The MetricMind dataset contains synthetic corporate sales transactions used
for analytical queries, semantic modeling, and business intelligence.

| Column | Description |
|---|---|
| order_id | Unique identifier for each order |
| order_date | Date of the transaction |
| year | Transaction year |
| quarter | Business quarter |
| month | Transaction month |
| region | Geographic business region |
| country | Country of the transaction |
| product_category | Product category |
| product | Product name |
| customer_segment | Enterprise, SMB, or Consumer |
| revenue | Revenue generated by the transaction |
| material_cost | Cost of materials |
| shipping_cost | Shipping expense |
| marketing_cost | Marketing expense |
| total_cost | Total operational cost |
| profit | Revenue minus total cost |
| margin | Profit as a percentage of revenue |
| orders | Number of orders |

## Business Metrics

### Revenue

Total value generated from sales.

### Cost

Sum of material, shipping, and marketing costs.

### Profit

Revenue minus total cost.

### Margin

Profit divided by revenue.

```text
Margin = Profit / Revenue
